Jadi hari ini kita belajar CSS, pada pertemuan kali ini belajar selector css. dari tag biasa, tag yang diinisialisasikan menggunakan class dan id. Ini adalah ta g paragraf biasa tanpa di inisialisasikan class ataupun id

Pembuatan Class

Nah untuk tag html yang diberi inisialisasi class maka nanti ketika akan styling di css , maka selectornya diawali tanda titik(.). Misal tag p ini aku beri class="class" maka nanti pas di css cara panggilnya = .class{atribut:value;}

Pembuatan Id

Nah untuk tag html yang diberi inisialisasi id maka nanti ketika akan styling di css , maka selectornya diawali tanda titik(#). Misal tag p ini aku beri id="id" maka nanti pas di css cara panggilnya = #id{atribut:value;}

Cara styling beberapa text

Caranya simpe aja,kalian hanya perlu menambahkan koma setiap antara tag di style css. Contoh h1,p,.artikel {properti:value;}
