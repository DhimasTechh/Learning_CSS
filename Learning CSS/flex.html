Belajar Box sizing danFloat

Hari ini belajar Box sizing dan cara membuat konten berada disamping content lain.

Box sizing adalah properti CSS yang menentukan bagaimana ukuran elemen HTML dihitung, termasuk padding dan border dalam perhitungan lebar dan tinggi elemen.Ada dua nilai utama untuk properti box-sizing:

content-box: Ini adalah nilai default. Dengan nilai ini, lebar dan tinggi elemen hanya mencakup konten. Padding dan border ditambahkan di luar lebar dan tinggi yang ditentukan, sehingga total ukuran elemen menjadi lebih besar. Misalnya, jika Anda memiliki elemen dengan lebar 300px dan menambahkan padding 10px serta border 5px, total lebar elemen akan menjadi 330px (300px + 20px padding + 10px border).

border-box: Dengan nilai ini, lebar dan tinggi elemen mencakup konten, padding, dan border. Jadi, jika Anda memiliki elemen dengan lebar 300px dan menambahkan padding 10px serta border 5px, lebar totalnya tetap 300px. Lebar konten akan disesuaikan dengan ruang yang tersedia setelah padding dan border diterapkan. Ini membuat pengaturan ukuran elemen menjadi lebih intuitif dan muda

Float CSS adalah properti dalam CSS yang digunakan untuk mengatur posisi elemen HTML agar "mengambang" ke sisi kiri atau kanan dari kontainer induknya. Elemen yang menggunakan properti float akan memungkinkan elemen lain di sekitarnya mengalir di sekitar elemen tersebut, menciptakan tata letak yang lebih fleksibel.
