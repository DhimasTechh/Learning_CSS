Hari Ini Ngapain Mas?

Jadi hari ini kita belajar CSS, pada pertemuan kali ini belajar selector css. dari tag biasa, tag yang diinisialisasikan menggunakan class dan id. Ini adalah tag paragraf biasa tanpa di inisialisasikan class ataupun id

Pembuatan Class

Nah untuk tag html yang diberi inisialisasi class maka nanti ketika akan styling di css , maka selectornya diawali tanda titik(.). Misal tag p ini aku beri class="class" maka nanti pas di css cara panggilnya = .class{atribut:value;}

Pembuatan Id

Nah untuk tag html yang diberi inisialisasi id maka nanti ketika akan styling di css , maka selectornya diawali tanda titik(#). Misal tag p ini aku beri cid="id" maka nanti pas di css cara panggilnya = #id{atribut:value;}
