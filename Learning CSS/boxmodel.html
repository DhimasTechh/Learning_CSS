Penjelasan

Jadi ada beberapa yg akan saya jelaskan :

Margin : adalah hal yg mengatur antar elemen tag, seperti jarak tag header dengan tag artikel yg mengatur adalah margin.

Padding : fokus pada isi background merah, padding = hal yg mengatur jarak antara isi konten dan border. konten diatas itu kalimat lorem itu. Saya setting jarak konten dan border 20px

Border : adalah garis tepi yg mengatur konten. Diatas itu saya setting border 1px solid black.
